# frontend/public

Copied to the site root unchanged.

| File | Purpose |
| --- | --- |
| `favicon.svg` | Site icon. |
| `icon-192.png`, `icon-512.png` | PWA / touch icons (generated by `npm run og`). |
| `og-image.png` | 1200×630 social preview (generated by `npm run og`). |
| `manifest.webmanifest` | PWA manifest. |
| `theme-init.js` | Applies the stored theme before first paint (no flash). Kept as an external file so the CSP can forbid inline scripts. |

`sitemap.xml`, `robots.txt` and the pre-rendered pages are generated into `dist/` at build time, not stored here.
